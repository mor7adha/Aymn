# AYMN QAHTAN — Portfolio

موقع شخصي بالعربية والإنجليزية مبني على السيرة الذاتية المرفقة.

## التشغيل

افتح `dist/index.html` مباشرة في المتصفح. لا يحتاج الموقع إلى تثبيت حزم أو خطوة بناء.

للمعاينة عبر خادم محلي، شغّل الأمر التالي من هذا المجلد ثم افتح `http://localhost:4173`:

```powershell
python -m http.server 4173 --directory dist --bind 127.0.0.1
```

## الملفات

- `dist/index.html`: الموقع الرئيسي، بالعربية افتراضيًا.
- `dist/styles.css`: التصميم المتجاوب ودعم اتجاه النص والطباعة وتقليل الحركة.
- `dist/script.js`: تبديل اللغة، قائمة الجوال، نسخ البريد، والتنقل.
- `dist/cv.html`: السيرة الذاتية بالإنجليزية، قابلة للطباعة والحفظ كـ PDF.
- `dist/favicon.svg`: أيقونة الموقع.

## النشر والتعديل

ارفع محتويات `dist` إلى استضافة مواقع ثابتة. الموقع محلي ولم يُنشر إلى رابط عام في هذه الجلسة.

المحتوى الإنجليزي والعربي موجود في قاموس `translations` داخل `script.js`. حدّث النص العربي الافتراضي في `index.html` أيضًا عند تغيير المحتوى. معلومات التواصل موجودة في `index.html` و`script.js` و`cv.html`.

روابط الاتصال والبريد تعمل من خلال تطبيقات الجهاز، ولا يوجد نموذج يجمع بيانات الزوار. تُحفظ اللغة المختارة محليًا إن سمح المتصفح بذلك. يستخدم الموقع Google Fonts مع خطوط بديلة عند عدم الاتصال بالإنترنت؛ لا توجد مكتبات JavaScript أو خدمات خلفية مطلوبة.
